## Lab Activity 0B: Android First Build

### Discussion

In this activity, I learned how to set up an Android development environment using Android Studio and create my first Android application using Java. I encountered some challenges when creating an Android Virtual Device, downloading the required system image, and configuring the project settings.

To complete the activity, I carefully followed the instructions, selected the appropriate device and project template, configured the project location, and chose Java as the programming language.

After completing the setup, I successfully ran my first Android application using the emulator. This activity helped me become more familiar with Android Studio, virtual devices, and the basic process of Android application development. It also gave me a better foundation for creating Android applications in the future.
